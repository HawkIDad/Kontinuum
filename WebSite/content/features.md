NoteBytez runs natively on iPhone, iPad and Mac. Each area below links to the step-by-step help for it.

## Capture and organise

- **Daily journal.** A journal page is ready every day, with quick capture and previous and next day navigation. {% helpLink "capture-and-journal", "todays-journal", "Use today's journal" %}
- **Documents and blocks.** Write in Markdown; every block gets a stable anchor you can link to. {% helpLink "documents-and-blocks", "create-document", "Create a document" %}
- **Notebooks.** Group notes for a project or a book, and promote a journal block into a notebook. {% helpLink "notebooks", "create-notebook", "Create a notebook" %}
- **Tags.** Add `#tags` inline or in front matter and browse them all in one place. {% helpLink "tags", "tag-browser", "Browse tags" %}
- **Tasks.** Turn any checkbox into a task with due dates, priority and repeats, and review them all in the Task Dashboard. {% helpLink "tasks", "task-dashboard", "Open the Task Dashboard" %}

## Connect and find

- **Wikilinks and backlinks.** Link notes with `[[double brackets]]`, see backlinks and unlinked mentions, and links update when you rename. {% helpLink "linking", "wikilinks", "Link two notes" %}
- **Block references and transclusion.** Reference a single block, or embed it live and edit it in place. {% helpLink "linking", "transclusion", "Embed a block" %}
- **Search.** Full-text search, scoped filters, advanced operators, a Quick Switcher and a Command Palette. {% helpLink "search-and-navigation", "full-text-search", "Search your library" %}
- **Saved views.** Pin a search, task filter or graph filter and it always shows current results. {% helpLink "search-and-navigation", "saved-views", "Save a view" %}

## See and shape your ideas

- **Graph.** A local graph of a note's links, a force-directed mode, filters, and insights that surface orphans, stale notes, hubs and clusters. {% helpLink "graph", "local-graph", "Explore the graph" %}
- **Canvas.** Boards of note, media and web cards with connectors and groups, JSON Canvas import and export, and boards you can bind to a note. {% helpLink "canvas", "create-canvas-board", "Create a canvas board" %}
- **Properties and templates.** Typed properties on notes, note templates grouped by job, and a gallery of ready-made packs. {% helpLink "properties-and-templates", "template-gallery", "Browse the template gallery" %}
- **Attachments.** Add images and PDFs to a note and preview them in place. {% helpLink "attachments", "embed-attachment", "Add an attachment" %}

## Sync, protect and share

- **Sync through iCloud.** See sync status and a log, sync on demand, and choose how conflicts are resolved: keep all versions, last write wins, or merge. {% helpLink "sync-and-conflicts", "sync-status", "Check sync status" %}
- **Backups.** Snapshots are taken before risky operations, and you can restore from any of them. {% helpLink "backup-and-restore", "restore-snapshot", "Restore a snapshot" %}
- **Sharing.** Share a library, invite people by email, and set read-only or read and write access for each. {% helpLink "sharing", "share-library", "Share a library" %}
- **Plugins.** Add capabilities with plugins that only get the permissions you grant. {% helpLink "plugins", "enable-plugin", "Enable a plugin" %}

## Bring your notes in and out

- **Migration.** Import an Obsidian or Logseq vault and keep the originals as a read-only archive. {% helpLink "migration", "import-obsidian", "Import from Obsidian" %}
- **Markdown import and export.** Import `.md` files, export a note, or export the whole library. {% helpLink "markdown-import-export", "export-library", "Export your library" %}
