## Purpose

Turn any line into a task with a Markdown checkbox.

## Prerequisites

A note is open in edit mode.

## Steps

1. Start a line with `- [ ]` and your task text, for example `- [ ] Book the room`.
2. Choose **Preview**.
3. Tap the checkbox to mark the task done. A finished task is written as `- [x]`.

## Expected result

The task shows in the note and in the Task Dashboard.
