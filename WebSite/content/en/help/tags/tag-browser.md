## Purpose

See every tag in your library.

## Prerequisites

A library is open.

## Steps

1. On iPhone, choose **Explore**, then **Tags**. On iPad and Mac, choose **Tags** under Library.
2. Read the list of tags with the number of notes each has.

## Expected result

You see all tags in the library.
