## Purpose

Add tags to a note inline or in front matter.

## Prerequisites

A note is open in edit mode.

## Steps

1. Type `#` followed by a word, for example `#research`. Matching existing tags appear as suggestions; choose one or keep typing.
2. Or add a `tags:` list to the note's YAML front matter.
3. Look under the title: each tag appears as a chip.

## Expected result

The note is tagged and appears under that tag in the tag browser.
