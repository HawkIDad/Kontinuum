## Purpose

Show another note's block live inside this note.

## Prerequisites

The block you want to embed exists.

## Steps

1. In edit mode, type `!((`. Blocks appear as suggestions.
2. Choose a block to insert `!((anchor))`.
3. Choose **Preview**. The block's content appears in a bordered box with a button to jump to the source.

## Expected result

The embedded block always shows the current content of its source.
