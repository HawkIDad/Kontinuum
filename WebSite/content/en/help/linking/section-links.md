## Purpose

Link to a specific heading inside a note.

## Prerequisites

The target note has at least one heading.

## Steps

1. Type `[[`, then the note's title, then `#`.
2. Headings from that note appear as suggestions. Choose one.
3. The link is inserted as `[[Title#Heading]]`.

## Expected result

The link opens the note at that heading.
