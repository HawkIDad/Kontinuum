## Purpose

Rename a note and have links to it update.

## Prerequisites

A note has links pointing at it.

## Steps

1. Open the note.
2. Edit the **Title** field at the top.
3. Open a note that linked to it.

## Expected result

Links to the renamed note now show the new title.
