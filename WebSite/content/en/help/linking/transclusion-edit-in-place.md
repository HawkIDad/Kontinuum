## Purpose

Change an embedded block without leaving the note that embeds it.

## Prerequisites

A note contains an embedded block (`!((anchor))`) and is in preview.

## Steps

1. In **Preview**, tap the embedded block to open it for editing.
2. Make your change.
3. Choose **Done** to write the change back to the source. Choose **Undo Edit** to revert the last edit.

## Expected result

The source note now contains your edit, and the embed shows it.
