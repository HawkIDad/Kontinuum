## Purpose

Understand how the Migration Assistant recognises Obsidian and Logseq.

## Prerequisites

A vault or graph folder.

## Steps

1. Choose your folder in the Migration Assistant.
2. NoteBytez looks for an `.obsidian` folder (Obsidian) or a `logseq` folder (Logseq).
3. If it cannot tell, use the **Source** picker to choose.

## Expected result

The correct source is selected.
