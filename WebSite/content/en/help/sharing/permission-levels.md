## Purpose

Set read-only or read and write access for each person.

## Prerequisites

A library is shared.

## Steps

1. Open **Settings**, then **Sharing**.
2. Find the person under **Participants**.
3. Change their **Permission**, or choose **Remove** to take away access. To end sharing for everyone, choose **Stop Sharing**.

{% admonition "note" %}Read Only lets a person read notes. Read & Write lets them edit as well.{% endadmonition %}

## Expected result

The person's access changes straight away.
