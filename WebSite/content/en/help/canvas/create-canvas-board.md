## Purpose

Create a board to lay notes and ideas out on an open canvas.

## Prerequisites

A library is open.

## Steps

1. Open **Canvas** (iPhone: Explore, then Canvas).
2. Choose **New Board**.
3. Type a name in **Board Name** and choose **Create**.

## Expected result

The board appears in the list; open it to start adding cards.
