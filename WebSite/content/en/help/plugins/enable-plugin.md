## Purpose

Install a plugin and choose what it may do.

## Prerequisites

You have a plugin to install.

## Steps

1. Open **Settings** and choose **Plugins**.
2. Choose **Add**.
3. Fill in the plugin's details and switch on only the permissions it needs.
4. Choose **Install**.

{% admonition "note" %}Plugins are in preview.{% endadmonition %}

{% screenshot "plugins/plugin-list-iphone-light.png", "The Plugins screen in preview, with an Add button.", "The Plugins screen." %}

## Expected result

The plugin appears in the list and adds its commands.
