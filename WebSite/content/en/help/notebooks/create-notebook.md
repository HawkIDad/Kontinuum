## Purpose

Create a notebook to group notes for a project or a subject.

## Prerequisites

A library is open.

## Steps

1. Open **Notebooks**.
2. Choose **+** (New Notebook).
3. Type a name in **Notebook Name** and choose **Create**.

## Expected result

The notebook appears in the list with 0 documents.
