## Purpose

File notes in a notebook.

## Prerequisites

A notebook exists.

## Steps

1. Open **Notebooks** and choose the notebook.
2. Choose **+** to create a note in it. The note is filed in this notebook.
3. To move a journal block into a notebook as a new note, use **Promote to Notebook**.

{% admonition "note" %}A note can belong to several notebooks. Notebook membership is also read from a `notebooks:` list in front matter when you import Markdown.{% endadmonition %}

## Expected result

The notebook lists the note and its count goes up.
