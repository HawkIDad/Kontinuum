## Purpose

Return your library to a saved snapshot.

## Prerequisites

At least one snapshot exists.

## Steps

1. Open **Settings** and choose **Backups**.
2. Choose the snapshot you want.
3. In **Restore this backup?**, read the warning: this replaces current data with the snapshot's contents.
4. Choose **Restore**, or **Cancel**.

{% admonition "warning" %}Restoring replaces your current data with the snapshot. Create a backup first if you might want the current state back.{% endadmonition %}

## Expected result

Your library matches the snapshot.
