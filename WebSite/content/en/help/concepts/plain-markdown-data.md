## What format are my notes in?

Plain Markdown. A note is text with headings, lists, links and tags that any Markdown tool can open.

## Can I leave with my notes?

Yes. Export a single note or your whole library at any time, including when your subscription has lapsed.

## Do other tools understand my links and tags?

Wikilinks and tags use the same syntax as Obsidian and Logseq. Notebook membership is written as a `notebooks:` list in front matter, plus a `#notebook/<name>` tag other tools can browse.
