## Purpose

Add a typed property, such as a date or a number, to a note.

## Prerequisites

A note is open in edit mode.

## Steps

1. Below the title, find the property row.
2. Type a name in **Property name**.
3. Choose a type: text, number, date, checkbox or list.
4. Choose **Add**, then enter the value.

## Expected result

The property appears on the note and can be edited or removed.
