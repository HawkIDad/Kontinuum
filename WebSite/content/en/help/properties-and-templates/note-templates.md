## Purpose

Create a template with fields that every new note starts with.

## Prerequisites

A template group exists.

## Steps

1. Open **Settings**, choose **Templates**, and open a group.
2. Under **New Template**, type a name and choose **Add**.
3. Open the template. Under **Add Field**, choose a type, name the field and choose **Add Field**.

## Expected result

New notes made from this template start with those fields.
