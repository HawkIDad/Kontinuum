## Purpose

Find notes by what their properties say.

## Prerequisites

Some notes have properties.

## Steps

1. Open **Search** and keep the **Content** scope.
2. Type the value you are looking for.
3. Choose a result to open it.

{% admonition "note" %}This version of NoteBytez does not have a dedicated property filter. Properties are stored in a note's front matter, so a content search for the value finds the note.{% endadmonition %}

## Expected result

Notes whose text includes that value are listed.
