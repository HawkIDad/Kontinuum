## Purpose

Save every note as Markdown.

## Prerequisites

A library with notes.

## Steps

1. Open **Settings** and choose **Export Library**.
2. Choose a folder.
3. A message tells you how many notes were exported.

## Expected result

Your notes are saved as Markdown files in the folder you chose.
