## Purpose

Turn a folder of `.md` files into a NoteBytez library.

## Prerequisites

A folder containing `.md` files.

## Steps

1. On the library screen, choose **Import Existing Markdown Folder**.
2. Choose the folder.
3. In **Import Preview**, review the counts of notes, links and tasks and each file.
4. Choose **Confirm Import**.

## Expected result

A new library holds one note for every file, with links and tasks indexed.
