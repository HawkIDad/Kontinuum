## What syntax can I use?

| You type | You get |
|---|---|
| `# Heading` | A heading (use more `#` for lower levels) |
| `**bold**`, `*italic*` | Bold and italic |
| `- item` | A list item |
| `> quote` | A block quote |
| Three backticks | A code block |
| `[text](https://example.com)` | A link to a web page |
| `[[Note title]]` | A link to another note |
| `[[Note title#Heading]]` | A link to a heading in another note |
| `((anchor))` | A reference to a block |
| `!((anchor))` | A live embed of a block |
| `#tag` | A tag |
| `- [ ] task`, `- [x] task` | An open and a done task |
| `tags:` in front matter | A list of tags |
| `notebooks:` in front matter | The notebooks the note belongs to |
