## Which shortcuts are there?

| Shortcut | Action |
|---|---|
| Command-N | New Note |
| Command-P | Command Palette |
| Command-O | Quick Switcher |
| Command-, | Settings |

The **View** menu on Mac also jumps to Today, Notebooks, Graph and Insights.
