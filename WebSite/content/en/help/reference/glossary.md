## What do the terms mean?

<dl>
<dt>Library</dt><dd>A collection of notes that syncs and is shared as one unit.</dd>
<dt>Journal</dt><dd>A page for each day, opened from Today.</dd>
<dt>Notebook</dt><dd>A named group of notes for a project or subject. A note can be in several.</dd>
<dt>Wikilink</dt><dd>A link to another note written as [[Note title]].</dd>
<dt>Backlink</dt><dd>A link from another note that points at the current one.</dd>
<dt>Unlinked mention</dt><dd>A note that mentions this note's title without linking to it.</dd>
<dt>Block</dt><dd>A paragraph, list item or heading, tracked separately with its own anchor.</dd>
<dt>Anchor</dt><dd>A short, readable identifier for a block.</dd>
<dt>Transclusion</dt><dd>Showing a block from another note live inside this one.</dd>
<dt>Tag</dt><dd>A label written as #tag.</dd>
<dt>Property</dt><dd>A typed field on a note, such as a date or number.</dd>
<dt>Template</dt><dd>A starting point with fields for new notes; templates are grouped into template groups and packs.</dd>
<dt>Saved view</dt><dd>A pinned search, task filter or graph filter that always shows current results.</dd>
<dt>Canvas</dt><dd>An open board of cards and connectors.</dd>
<dt>Conflict</dt><dd>The same note edited on two devices before they synced.</dd>
<dt>Snapshot</dt><dd>A saved copy of your library that you can restore.</dd>
<dt>Grace period</dt><dd>The short time of full access after a subscription lapses.</dd>
</dl>
