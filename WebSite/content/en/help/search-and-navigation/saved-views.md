## Purpose

Pin a search, task filter or graph filter so it always shows current results.

## Prerequisites

You have a search, a Task Dashboard filter or a graph filter you want to keep.

## Steps

1. On Search, choose **Save This Search**. On the Task Dashboard, choose **Save These Filters**. On the graph filter bar, choose **Save as View**.
2. Type a name and choose **Save**.
3. Open **Saved Views** (under Explore) and choose the view.

{% screenshot "search-and-navigation/saved-views-iphone-light.png", "The Saved Views screen.", "Saved Views." %}

## Expected result

The view opens and re-runs its query, so it always shows current results.
