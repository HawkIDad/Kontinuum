## Purpose

Jump to a screen or run an action by typing its name.

## Prerequisites

A library is open.

## Steps

1. On iPhone, choose **Explore** and then **Command Palette**. On iPad and Mac, press Command-P.
2. Type to filter. Screens (Today, Notebooks, Graph and so on) and actions (New Note, New Notebook, New Canvas Board, Promote to Notebook, Sync Now, Open Settings and more) are listed.
3. Choose an entry to run it.

{% screenshot "search-and-navigation/command-palette-iphone-light.png", "The Command Palette listing screens and actions.", "The Command Palette." %}

## Expected result

You go to the screen, or the action starts.
