## Purpose

Learn how every block in a note gets a stable anchor you can refer to.

## Prerequisites

A note with some text.

## Steps

1. Write your note in blocks: paragraphs, list items and headings each become a block.
2. In any note, type `((` to see a list of blocks you can refer to. Each is shown by its anchor and its heading path.
3. Choose a block to insert a reference to it.

## Expected result

The anchor stays with its block, so references keep pointing at the same content.
