## Purpose

Use Markdown for headings, emphasis, lists, quotes and code.

## Prerequisites

A note is open in edit mode.

## Steps

1. Type Markdown directly: `# Heading`, `**bold**`, `*italic*`, `- list item`, `> quote`, and fenced code blocks with three backticks.
2. Choose **Preview** to see the formatted result.
3. Choose **Edit** to go back to the source.
